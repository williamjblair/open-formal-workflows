What the deployment contributes

It makes exact source identity, environments, checks, errors, and stale evidence easier to inspect together.

What the deployment cannot do

It cannot approve, merge, establish mathematical truth, or record maintainer acceptance. Maintainer decisions remain outside the generated evidence.

The evidence path

A narrow path from source work to a maintainer decision.

Each stage has one job. Evidence can inform a decision, but it cannot become the decision by changing labels or crossing systems.

  1. 01 / SOURCE

    Formal Conjectures source

    Formal Conjectures owns the declaration, pull request identity, repository policy, and current source state.

  2. 02 / EVIDENCE

    Pinned Lean execution

    LeanEval and Comparator bind runs to exact inputs, tool revisions, environments, and typed outcomes.

  3. 03 / REVIEW

    Evidence review

    The ReviewReport preserves passes, errors, limitations, and not-evaluated states without creating authority.

  4. 04 / DECISION

    Maintainer records decision

    Only the source maintainer can decide acceptance. Until then, the disposition remains empty and standing does not change.

Vela Protocol 1 is the technical substrate.

It keeps evidence, review, authority, and standing as separate records. problems.science provides public orientation and contribution context without becoming a source of truth.
